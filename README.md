# Gift 🐾

Маленький сайт із трьома запитаннями, котиками та вибором подарунка.
Статичний HTML/CSS/JavaScript; збірка та встановлення залежностей не потрібні.

## Публікація в Netlify

1. У Netlify оберіть **Import from Git → GitHub → artem200400/gift**.
2. Branch: **main**.
3. Build command: залишити порожнім.
4. Publish directory: **.** (корінь репозиторію; налаштовано в `netlify.toml`).
5. Натиснути **Deploy**. Netlify надасть адресу `*.netlify.app`.

## Підключення пошти

Адреса отримувача вже налаштована: `hot1agent007@gmail.com`.

1. Після публікації відкрийте `/setup.html` на вашому сайті.
2. Натисніть кнопку підключення та пройдіть перевірку FormSubmit, якщо вона з’явиться.
3. Відкрийте лист від FormSubmit у пошті й підтвердьте активацію. Перевірте «Спам».
4. Пройдіть анкету з тестовими відповідями й перевірте отриманий лист.
5. Після перевірки надішліть головне посилання дівчині.

Надсилання потребує інтернету й активованої форми FormSubmit. Фактичну доставку в поштову скриньку ще не підтверджено. Якщо надсилання не вдасться, з’явиться кнопка копіювання відповідей. Незавершені відповіді очищаються при перезавантаженні сторінки.

## Файли

- `index.html`, `style.css`, `app.js` — сайт.
- `assets/` — ілюстрації.
- `setup.html` — одноразове підключення пошти.
- `netlify.toml` — параметри публікації.

Немає серверної частини, секретних ключів або бази даних. Адреса отримувача є частиною клієнтського коду.
